# UPCA Real Estate Marketing and Media

Scroll-scrubbed hero film site (TanStack Start + React 19 + Tailwind), exported as a static site for Cloudflare Pages.

- Pages build command: `npm run build`
- Pages build output directory: `dist`
- Consultation form opens the visitor's email app addressed to the support address in `src/components/upca/content.ts`.
- `npm run build:worker` builds the original server-rendered Worker version (needs a database for the form).
- The previous React site is in git history at commit `0ad6355`.
